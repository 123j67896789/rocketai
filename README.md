# MOONBOUND

3D autonomous rocket mission built with Three.js and Brain.js.

Open `index.html` in a modern browser. Drag to orbit; scroll to zoom. Start, pause, and reset the mission.

The AI is a small neural-network autonomy simulation, not conscious free will.

## GitHub Pages
A deployment workflow is included at `.github/workflows/deploy.yml`. Set Settings → Pages → Source to GitHub Actions.
